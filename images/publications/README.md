# images/publications/

Cover images uploaded through the admin screen
(`pages/admin-publications.html` → Edit → *Upload image*) are saved here by
`api/upload.php`. Filenames are generated (`<slug>-<random>.jpg`), so you can
also drop files in by FTP and paste the path into the **Cover image path**
field, e.g. `images/publications/my-photo.jpg`.
